### Favonis

**一个自带云端电脑的 AI 工作平台。**

说清你想完成的目标，Favonis 就可以在同一项目中查资料、处理数据、制作文档、编写与运行代码，以及发布应用。

文件、上下文与工作进度持续保留。关掉本地电脑后，任务仍可在云端继续；换一台设备，也能回来查看成果、补充要求和接着工作。

#### 你可以用它做什么

- **研究与分析**：查阅网页、图片与文档，整理信息，形成报告和分析结论。
- **创作与交付**：制作可编辑的文档、表格、演示文稿及视觉素材。
- **开发与发布**：搭建应用、运行代码、查看预览，并发布网站。
- **持续推进项目**：跨对话复用项目文件、工作背景与长期记忆。
- **跨设备接续**：在电脑和手机之间切换，云端任务持续执行。

### 体验背后的工程

我们自主构建连接智能体决策、任务执行与成果交付的基础设施。

| 技术 | 主要方向 |
| --- | --- |
| **FavonCloud** | 弹性云端电脑、预置工作环境与按需资源分配。 |
| **FavonMind** | 长期记忆治理，保留用户与项目的有效背景。 |
| **FavonCortex** | 上下文选择与后台压缩，支撑长周期任务。 |
| **FavonSearch** | 协同检索与分析网页、图片、文档和媒体内容。 |
| **多模型路由** | 根据任务需求匹配模型能力，兼顾质量、时延与成本。 |
| **PWA + LocalFirst** | 本地快速访问、后台同步，以及已缓存内容的离线访问。 |
| **Go 网络与 Office 引擎** | 并发信息处理与原生办公文档生成。 |

我们的技术栈包括 **Go、TypeScript、Vue、Nuxt、PostgreSQL 和 Redis**，通过共享契约连接 Web、原生客户端与浏览器扩展。

### 我们坚持的原则

- **清晰易用**：让界面服务于任务，让复杂工作更容易理解和完成。
- **性能优先**：将响应速度、资源效率与执行成本视为产品的基本要求。
- **工作连续**：保留有价值的文件与上下文，让项目可以随时继续。
- **用户驱动**：从真实任务和用户反馈中发现问题，持续改进。

### About Us

**Suzhou Favonis** is an AI technology company building intelligent agents and the infrastructure that enables them to do real work.

Our team brings together experience in algorithm competitions, systems engineering, and product design. We develop our own agent infrastructure, with a focus on persistent memory, context optimization, elastic cloud execution, and responsive user experiences.

Our goal is simple: make it easier for people to turn an idea into something they can use.

### Favonis

**An AI workspace with its own cloud computer.**

Describe what you want to accomplish. Favonis can research, process data, create documents, write and run code, and publish applications within the same project.

Files, context, and progress stay together. Tasks can continue in the cloud after you close your computer, and you can return from another device to review results or keep working.

#### What you can do

- **Research and analyze**: Explore web pages, images, and documents, then organize findings into reports and useful conclusions.
- **Create and deliver**: Produce editable documents, spreadsheets, presentations, and visual assets.
- **Build and publish**: Develop applications, run code, inspect previews, and publish websites.
- **Continue long projects**: Reuse project files, working context, and memory across conversations.
- **Work across devices**: Move between desktop and mobile while cloud tasks continue.

[Start a project →](https://ai.favonis.com/app)

### Engineering Behind the Experience

We build the infrastructure that connects an AI agent's decisions to reliable execution and usable results.

| Technology | Focus |
| --- | --- |
| **FavonCloud** | Elastic cloud computers, prepared environments, and resources allocated on demand. |
| **FavonMind** | Long-term memory that preserves useful context about users and projects. |
| **FavonCortex** | Context selection and background compression for long-running tasks. |
| **FavonSearch** | Coordinated research across web pages, images, documents, and media. |
| **Model Routing** | Match model capabilities to task requirements while managing latency and cost. |
| **PWA + LocalFirst** | Fast local access, background synchronization, and offline access to cached content. |
| **Go Network & Office Engines** | Concurrent information processing and native document generation. |

Our stack includes **Go, TypeScript, Vue, Nuxt, PostgreSQL, and Redis**, with shared contracts connecting our web, native, and browser-extension clients.

### Our Principles

- **Clarity**: Keep interfaces focused and make complex work easier to understand.
- **Performance**: Treat responsiveness, resource efficiency, and execution cost as product requirements.
- **Continuity**: Preserve useful work so users can return to a project without starting over.
- **User feedback**: Improve the product through real tasks and the people who rely on it.
